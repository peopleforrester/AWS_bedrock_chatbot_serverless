# Interactive LLM Architecture Diagrams

An interactive web-based visualization of Large Language Model (LLM) architectures, Retrieval Augmented Generation (RAG), and application integration patterns.

## Features

- **LLM Internals Visualization**: Interactive diagram showing the core components of transformer-based LLMs including tokenization, embedding layers, attention mechanisms, and output generation.

- **RAG Architecture Visualization**: Comprehensive visualization of Retrieval Augmented Generation, showing how external knowledge bases are integrated with LLMs.

- **Application Integration Patterns**: Diagram showing how applications connect to LLMs via APIs, including frontend, middleware, and various backend services.

## Technologies Used

- **React**: Frontend UI library
- **TypeScript**: Type safety for JavaScript
- **Vite**: Fast build tooling
- **React Flow**: Interactive node-based diagrams
- **Zustand**: State management

## Getting Started

1. Clone the repository
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm run dev
   ```
4. Open your browser to the URL displayed in the terminal

## Learn More

This visualization tool helps you understand:

- How transformer-based LLMs process text and generate outputs
- How RAG systems enhance LLMs with external knowledge
- How to architect applications that effectively integrate with LLM services
