# AWS Bedrock Serverless Chatbot

Serverless chatbot demo built on AWS Bedrock, with an interactive diagram that
shows how a request travels through the model integration.

## Layout

| Path | What it holds |
|---|---|
| `claude_code/` | The chatbot implementation, including the interactive model-interaction diagram |
| `claude_code_demo/` | Demo harness and walkthrough assets |

## Status

Demo material. Kept as a reference implementation rather than a maintained
service.
